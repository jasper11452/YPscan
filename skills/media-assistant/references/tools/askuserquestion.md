# AskUserQuestion（宿主交互对话框）

需要用户选择、补充、确认或决策时，必须调用宿主 `AskUserQuestion`，不得用普通聊天文本提问。只要下一步依赖任何用户回复，就在同一轮调用本工具，绝不以问句、让用户打字或被动等待作为最终回复。问题只问用户可决定的、且缺失会实质改变结果的事项。

## 参数结构

```json
{
  "questions": [
    {
      "header": "标题（必填，如：悦普识星确认 / 悦普识星决策 / 下一步）",
      "question": "问题正文（必填，完整上下文）",
      "options": [{ "label": "选项短标签（必填）", "description": "选项说明（必填）" }],
      "multiSelect": false
    }
  ]
}
```

## 数量上限

- 一次调用最多 **4 个问题**；多个待澄清项合并为一次调用，不逐项追问。
- 每个问题 **2–4 个选项**，label 和 description 均非空。
- 选项必须是可执行的答案或动作：用户只点击 label 就能让流程继续，不能再要求用户另行输入该选项本该承载的值。
- 禁止使用“返回补充”“确认并补充”“自行填写”“请输入”等伪选项。对过期或缺失的时间，必须给出至少两个未来的绝对日期时间；对可编码的“不限”，直接规范化而不弹窗。
- `multiSelect` 必须显式声明：`true` 表示可多选（答案可共存），`false` 表示单选（答案互斥）。
- 宿主默认保留自定义输入框。不要添加虚假的 `其他` 选项、自定义字段参数或封闭式限制，也不要替用户选择默认答案。

## 展示规则

- `header`：简短分类标题，不带换行。
- `question`：承载完整上下文（如缺失字段清单、风险提示；**MCN 机构名单表格除外**——它必须在调用 `AskUserQuestion` 前作为用户可见正文展示，`question` 只写决策问题）。内容太长必须**主动换行**：
  - 按空格断行，优先在空格处断开，不要从标识符中间切断；
  - 正文较长时按约 40 个字符分行，多行用 `\n` 连接；
  - 行首保持固定前缀完整（如 `[悦普识星 决策]`），断行不拆前缀。
- `label`：短动作词（如 `询价机构`、`结束本次`、`选择候选机构`），超长时同样换行。
- `description`：一句话补充该选项后果，换行规则同上。

## 展示模式与时机

`AskUserQuestion` 没有独立的 `type` 参数；警示、授权和普通决策都使用同一结构，通过标题、正文、选项和 `multiSelect` 表达。

| 类型      | multiSelect | 示例                          |
| --------- | ----------- | ----------------------------- |
| 决策/单选 | false       | `询价机构` / `人工拓展并提报` |
| 多选      | true        | 多平台、多字段同时确认        |

- **候选消歧**：当 Provider 返回机构名模糊或不唯一候选时，只展示真实候选并让用户选择；不得把已经成功发送的机构放入后续调用。
- **不得预设答案**：选项顺序不表示推荐；用户拒绝/取消/关闭/超时/缺失答案是当轮终止，不得替用户推断或代选。

## Hook 生成的问题

- Hook 给出 `ASK_USER_QUESTION_ARGS` 时，**逐字原样传递**，不得改写、删减、重排或重建问题、选项或挑战 ID。
- `search_creators` 成功并返回精确 `SAVE_EXCEL_ARTIFACT_ARGS` 后立即调用 `ypscan_save_excel_artifact`，保存成功后再调用 `rank_mcns`。排序成功后先输出当前响应的完整 MCN Markdown 表格作为用户可见正文（禁止改成项目符号或编号列表），再原样展示此前保存工具返回的绝对 `data.file_path`，最后构造宿主问题；不输出 `creators_export_path` 或 Excel 下载链接。表格和本地路径不得放进 `question`，不得留到弹窗返回后补发。MCN 非空时选项固定为 `询价机构` 和 `人工拓展并提报`，为空时表格增加“暂无匹配机构”空态行，选项固定为 `人工拓展并提报` 和 `结束本次`。原始需求里说“直接手扒”不算本次分支答案，只有当前弹窗答案决定路径。
- 登录、验证码、重试、暂停或结束人工 Browser 流程时必须弹窗；平台原生导出或对话名单成功交付后不追加完成确认。
- 只有用户选择了对应动作，Agent 才继续该动作；关闭、取消、超时或无答案即结束当前轮次。
