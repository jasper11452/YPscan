# 相似达人发现与核验规则

平台“相似达人/相似博主”只负责发现，不继承参考账号的合格状态。每个新账号仍须依据插件 Runner 在当前 run 中保存的页面和详情证据，按同一需求和同一证据标准复核。

## 五项核验

1. 内容主题：近期真实内容持续覆盖需求大类；宽搜索词或平台推荐标签不能单独证明。
2. 真实人设：主页、平台人设标签和近期内容能共同支持身份/关系；无法确认时标记待核验。
3. 高频场景：目标场景在受限近期样本中重复自然出现，不以单条偶发内容代替。
4. 内容结构：历史内容存在教程、复盘、对话、挑战、模板或其他可深度植入结构；纯资讯/纯采访等负向格式按项目策略降级。
5. 价格带：只比较同平台、同内容形式/时长和同粉丝段的真实报价，不跨档借价。

## 来源与边界

- 保存发现入口、参考达人稳定 ID、候选稳定 ID、采集时间和平台 URL。
- 相似来源进入搜索池后先去重，再执行硬条件、商业证据和业务分层。
- 不从相似关系推断粉丝粘性、商单稳定性、语言能力、报价、档期或合作意愿。
- 登录、验证码、权限或来源结构不可用时停止该路径，不绕过平台限制。
- 相似推荐入口仅在 Runner 当前适配能力覆盖时使用；来源变化不能替代本轮真实内容和商业证据。
