## 权威与维护边界

- 业务行为以 Skill 和用户最新要求为准；工具卡描述对应工具契约；Spec 描述实现，不创造另一套业务规则。
- Wiki 只维护工程方法、资料导航、同步矩阵和发布流程，不复制完整业务链路、字段清单或当前版本号。
- AGENTS 保留必须遵守的短规则，详细步骤链接到 Wiki；发现冲突就修正过时来源，不靠再补一段解释维持两套正文。
- 一次任务结束前报告：已更新哪些资料、哪些类别不受影响及原因、已做哪些验证、哪些仍未验收。涉及用户已有改动时保留并明确其归属。
- 新经验优先并入现有主题；只有独立且可长期复用的主题才新建页面，并从这里链接。没有可靠资料时回到代码、测试和真实响应，不凭空补 Wiki。
